1. Executive Summary & Overview

Publication Title: Machine learning models in web applications: A comprehensive review[cite: 1, 2]

Authors: Kshiteesh Mani & Ajitha K.B. Shenoy[cite: 1]

Journal & Publisher: ICT Express, Elsevier (2025)[cite: 1]

This paper evaluates the critical role of Artificial Intelligence (AI) and Machine Learning (ML) architectures in optimizing system performance and fortifying cyber defenses within contemporary web applications[cite: 1]. The scope covers two core domains:

  • Backend Technology Stack Comparison: Analyzing Python versus Node.js ecosystems for serving, scaling, and maintaining ML models in production backends[cite: 1].
  • ML-Augmented Web Application Firewalls (WAF): Reviewing state-of-the-art anomaly and signature detection algorithms designed to neutralize malicious web traffic (such as SQL Injection and Cross-Site Scripting)[cite: 1].
Methodology Note: The paper synthesizes recent advancements across web security and backend framework integrations published between 2019 and 2024[cite: 1].

2. Key Strengths & Analytical Contributions

  • Cross-Disciplinary Integration: Bridges modern software architecture practices (backend engineering) with proactive cybersecurity controls (WAF deployment)[cite: 1].
  • Structured Survey Coverage: Categorizes ML and Deep Learning detection techniques systematically across tabulated comparative matrices[cite: 1].
  • Unbiased Architectural Evaluation: Evaluates microservices, hybrid stack solutions, and native integrations without leaning dogmatically toward a single vendor or framework[cite: 1].

3. Limitations & Research Gaps

  • Absence of Empirical Benchmarking: Relies primarily on secondary literature review rather than providing original experimental metrics (e.g., side-by-side latency, request throughput, or memory overhead tests).
  • Constrained Adversarial Analysis: Offers limited discussion on countermeasures against adversarial attacks targeting ML classifiers embedded within firewalls.
  • Operational MLOps Omissions: Provides minimal depth regarding long-term production maintenance, automated retraining pipelines, and managing data drift at enterprise scale.
